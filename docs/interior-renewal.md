# 내부 화면 디자인 정리

기존의 밝은 중립색 배경, Paperlogy, 초록 강조색과 TDS 컴포넌트를 유지한다.
홈의 정보 계층과 카드 구성을 요청 상세, 입력, 전달·수령, 채팅, 거래처와 계정 화면에 적용했다.

- 일반 내부 카드의 바깥 여백은 16, 반경은 기존 24를 사용한다. 유리 효과는 기존 홈·탭·알림 버튼 범위를 유지한다.
- `PageFrame`은 선택적인 고정 상단 내용과 역방향 스크롤을 지원한다. 일반 화면은 기존 방향으로 스크롤한다.
- 탭·내부 화면 모두 `PageFrame`의 헤더를 사용한다. TDS 표면과 하단 구분선 안에서 뒤로가기·제목·우측 동작을 왼쪽 기준으로 정렬하고, 안전 영역과 48px 터치 영역을 확보한다. 헤더는 본문 스크롤 밖에 두며 긴 제목은 말줄임한다. 채팅은 프로필·역할, 요청 상세는 상품·진행 상태를 보조 정보로 표시한다.
- 헤더·본문·상태바 안전 영역은 같은 `background` 토큰을 사용해 모든 화면의 바탕을 연결한다. 헤더 자체의 배경 채우기는 없애 본문 바탕이 그대로 드러나며, 하단 탭의 첫 화면은 모두 상단 구분선도 생략한다. 카드에만 기존 밝은 표면을 쓴다.
- 홈의 사입 현황 제목은 굵게, 상대방 확인 대기 건수는 별도의 큰 숫자로 표시한다. 미송 재확인의 시계는 제목 줄에 정렬한다. 대기가 있는 시계에 홈 진입·상태 변경 시 TDS `shine` 효과를 한 번 재생한다. 화면 아래쪽의 시계는 스크롤해서 보일 때까지 재생을 미루며, 다른 탭으로 이동하거나 동작 줄이기를 켜면 효과를 제거한다.
- 알림은 날짜별 TDS 목록으로 구성한다. 고정된 전체/안 읽음 탭, 종류별 아이콘, 본문, 시간을 순서대로 보여주며 읽지 않은 항목은 초록 강조와 텍스트로 구분한다. 알림을 열면 기존 읽음 처리와 대상 화면 이동을 유지하고, 안 읽음 목록이 비면 전체 목록으로 돌아가는 동작을 제공한다.
- 요청 상세는 상품·옵션·상태를 먼저 보여주고, 확보·전달 대기·전달·미송 수량을 두 열로 구분한다. 사입·배송 정보, 요청 관리, 전달 내역과 처리 이력을 각각 묶는다.
- 수락·추가 확보·미송 답변·수령 확인은 상태에 맞는 하단 주요 동작으로 노출한다. 수정·협의·관련 채팅 등 이동 동작은 TDS 목록 행으로 표시한다. 저장·취소·확정의 오류 처리와 중복 실행 방지는 기존 `ActionButton`을 사용한다.
- 새 요청과 프로필 입력은 관련 항목을 카드로 묶는다. `Field`는 TDS 입력창 자체 여백을 사용해 이중 가로 여백을 없앴다.
- TDS 글자 크기 130%를 넘으면 단일 선택 칩을 TDS 라디오 항목으로 표시한다. 긴 옵션이 작은 화면 밖으로 넘치지 않고 줄바꿈되도록 한다.
- 채팅은 최근 메시지부터 열리며, 이전 내용을 읽다가 전송하면 새 메시지로 이동한다. 날짜는 날짜별로 한 번 표시하고 메시지에는 시각과 읽음 상태를 표시한다. 자동 업무 기록은 요청 상세로 이동하는 별도 카드로 구분한다.
- 채팅 상단에는 연결된 요청, 하단에는 입력·사진·요청 변경·전송을 둔다. 키보드 등으로 사용 가능한 화면 높이가 600 이하로 줄면 상단 요청 카드를 숨겨 대화 공간을 확보한다.
- 하단 탭은 시스템 하단 여백이 24보다 큰 기기에서 12 아래로 이동한다. Android의 작은 제스처 여백이나 시스템 탐색 버튼 영역은 그대로 확보한다.
- 공식 소셜 로그인 아트워크와 크기를 유지하면서 기존 장식 구현을 공개 `TdsAssetFrame` 조합으로 교체했다.

검증 명령:

```sh
dart tool/tds_guard/tds_guard.dart check
flutter analyze --no-pub
flutter test --no-pub
flutter drive --no-pub -d <simulator-id> --driver=test_driver/local_app_driver.dart --target=integration_test/local_app_test.dart
```

`test/local/interior_navigation_test.dart`에서 최근 대화 표시·전송·키보드, 시스템 하단 여백 0/24/34와 실제 TDS 글자 크기 180%에서 320/390/430 너비의 내부 화면을 확인한다. 통합 테스트는 로그인, 양쪽 역할 홈, 요청 상세·입력, 확보·전달·수령, 채팅·키보드, 거래처·프로필·알림 설정·문제 신고 화면을 캡처한다. 결과 이미지는 `.context/interior-refresh/`에 보관한다.
