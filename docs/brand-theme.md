# 딥그린·라임 브랜드 테마

2026-10-11 승인된 색상 참고 이미지와 로고를 적용했다. 기존 Figma 배치, Paperlogy,
TDS 컨트롤, 내비게이션과 업무 로직은 유지한다. 앱은 기존 AIT 설정에 따라 밝은 모드로
표시하며, 런처 아이콘·서버·DB에는 변경이 없다.

## 로고와 팔레트

`assets/logos/saip_samchun_sc_symbol.svg`는 사용자가 제공한 원본 파일이다.
원본 검정 `#111111`, 경로, 415:254 비율을 유지하고 색상 필터 없이 `TdsAssetImage`로
표시한다. 온보딩·로그인은 폭 112, 홈 상단은 폭 40이며 계정명은 남은 영역에서 말줄임한다.

| 용도 | 값 |
| --- | --- |
| 주요 버튼·선택·포커스·내 채팅 | `#0C483E` |
| 제목·중요 수량 | `#07231C` |
| 본문·보조 설명·입력 안내 | `#3D5C50` |
| 화면 바탕·일반 카드 | `#EFF4E4` / `#F2FFE8` |
| 선택 탭·작은 강조 | `#C6FF3A` |
| 비활성·장식 | `#6B8377` |
| 주요 버튼 글자 | 흰색 |
| 보조 버튼 | 딥그린 12% 배경 + 딥그린 글자 |

기존 blue 계열 테마 토큰에 브랜드 초록을 대응시켜 TDS 컴포넌트가 같은 팔레트를
사용하게 한다. 오류·위험 색상은 유지한다. TDS의 nullable 보조 버튼 테마 훅으로
짙은 초록이 기본 명도 보정에 의해 회색으로 바뀌는 것을 방지한다. 기본 패키지 테마의
색 보정·비활성·로딩·키보드 동작은 유지한다.

## 표면

`FigmaSurface`의 기본 스타일은 불투명한 `solid`다. 홈의 확인할 일 카드,
사입 현황/오늘 업무 카드, 하단 탭만 `glass`를 사용한다. 거래 목록·입력 폼·상세 정보는
불투명 표면으로 유지한다.

- 반경 24, 기존 바깥 여백·안쪽 여백·터치 영역 유지.
- 흰색 55% → `#FAFFF2` 32% 표면, sigma 16 배경 블러.
- 흰색 95% 상단·측면 테두리, 딥그린 15% 하단 경계.
- 딥그린 8%, 아래 8, blur 24의 그림자와 정적인 빛 반사.
- 홈 바탕은 라임 14%의 옅은 방사형 그라데이션. 글자·아이콘은 불투명하게 표시.
- 카드 내부로 블러를 클리핑하고 겹치지 않는 홈 카드만 `BackdropGroup`을 공유.
  하단 탭은 별도 필터를 사용한다. 새로운 효과 패키지·셰이더·애니메이션은 없다.
- 고대비 모드에서는 블러·투명도·그림자를 제거하고 불투명 표면과 딥그린 테두리를 사용.

## 검증

원본 SVG 바이트 일치를 확인했다. 유리 표면과 강조·보조 버튼 배경의 합성 색상을 기준으로
본문 대비는 최소 5.41:1, 주요 버튼은 10.44:1, 보조 버튼은 최소 7.65:1이다.
색상 계산 결과와 캡처는 `.context/brand-refresh/`에 보관한다.

화면 테스트는 320/390/430 너비와 실제 TDS 100/180% 글자 크기에서 홈 로고·긴 계정명,
온보딩·로그인과 탭 이동을 확인한다. 별도 테스트에서 유리 표면의 버튼이 눌리는지,
고대비 전환으로 레이아웃이 바뀌지 않는지 확인한다. 기존 앱 업무 테스트와 TDS
버튼·입력·체크박스·스피너·하단 CTA·채팅 말풍선 테스트도 실행한다.

기기 통합 테스트는 온보딩·소셜 로그인 화면과 양쪽 역할의 홈, 홈 스크롤, 요청 상세,
네이티브 입력, 확보·전달·수령, 채팅을 캡처한다. 테스트는 격리된 메모리 데이터를
사용하며 실제 OAuth 로그인이나 서버 데이터는 변경하지 않는다.

최종 검증: 정적 분석 이슈 없음, 기존 앱 테스트 36개 통과(웹 전용 7개 제외),
브랜드 표면·글자 크기 테스트 7개 통과, 관련 TDS 테스트 40개 통과. 탭 내부 정렬을
보정한 뒤 화면 회귀 테스트 13개를 다시 통과했고, iOS 26.5 / Android API 36.1의
온보딩·로그인·업무 통합 테스트도 통과했다. 최종 캡처는
`.context/brand-refresh/after/`, 기존 홈과의 비교는 `.context/brand-refresh/comparison.png`다.
