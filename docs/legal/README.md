## 3. 주요 법률 판단과 문서 작성 원칙

### 중개수수료는 있지만 조건 확정 전에는 청구하지 않는다

중개수수료를 받는 사업 구조를 명시하되, 부담자·금액·산식·세금·발생 요건·결제·환급 조건을 사전 고지하고 동의받기 전에는 운영자의 수수료를 청구하지 않도록 정했다. 과거 이용분에 대한 소급 청구도 금지했다. 이는 거래 상대 회원 사이에서 별도로 합의하는 상품대금·사입대행료·운송료를 무료로 만든다는 뜻은 아니다.

### 가입 연령 제한과 법정대리인 보호절차는 구별한다

가입을 일률적으로 만 14세 또는 만 19세 이상으로 제한하지 않았다. 대신 만 14세 미만의 동의 기반 개인정보 처리에는 법정대리인의 확인된 동의를, 미성년자의 유료 계약에는 민법상 동의·대리 및 취소 규정을 적용했다. 처분을 허락한 재산·허락받은 특정 영업 등 법률상 예외도 구별했다.

### 사업자 간 거래도 실제 적용 법령을 확인한다

서비스의 주된 목적은 사업상 사입이지만 모든 거래를 소비자보호법 적용 제외로 선언하지 않았다. 전자상거래법 제3조의 사업자 거래 제외와 예외, 운영자 자체 유료 서비스의 통신판매 해당 여부, 실질적인 통신판매중개 여부를 확인해야 한다. 개인 제공자가 참여하면 2026년 시행된 개인 간 거래 관련 제20조의4의 적용 여부도 확인한다.

### ‘중개자’ 표시만으로 운영자의 책임이 사라지지 않는다

직접 사입·배송 의무는 해당 거래 당사자에게 있다는 점을 명시하되 운영자의 과실, 수수료·환급, 개인정보 보호, 법정 중개 의무 및 법률상 연대책임은 배제하지 않았다. 납부 수수료만을 손해배상 한도로 정하거나 운영자 소재지 법원을 무조건 전속관할로 두지 않았다.

### 계약 이행, 제3자 제공, 국외 이전의 근거는 각각 확인한다

개인정보 보호법 제15조 제1항 제4호는 계약 이행·요청된 계약 체결 준비에 필요한 수집·이용의 근거가 될 수 있다. 그러나 그 자체는 독립적인 상대 회원에게 제공하는 제17조의 포괄 근거가 아니다. 제3자 제공과 국외 이전이 겹치는 경우 각각의 요건을 검토한다. 처리방침 전체에 대한 하나의 필수 체크박스로 이를 대신하지 않는다.

### 대한민국 기본 저장과 모든 정보의 국내 처리는 다르다

서버 기본 저장 국가는 운영자 확인에 따라 대한민국으로 기재했다. 다만 해외 지원자의 조회, 백업·로그·재수탁자와 DiceBear 직접 호출은 별도 검토 대상이다. 실제 국가를 확인하지 않고 ‘국외 이전 없음’ 또는 ‘모든 정보 국내 보관’으로 표시하지 않았다.

검토 시점의 작업트리 기준이다. 다른 작업에서 코드가 바뀌면 실제 게시 직전에 다시 대조한다. 소스만으로 운영 데이터베이스의 지역·백업·수탁 계약·OAuth 권한·관리자 접근 설정까지 검증한 것은 아니다.

주요 확인 결과:

- 신규 소매업자는 사업자정보·사업자등록증이 필수이고, 신규 사입삼촌에게 같은 서류가 공통 필수는 아니다. 과거 사입삼촌의 잔존 서류는 별도 정리가 필요하다.
- 초대 코드 조회·연결 대기 과정에도 일부 프로필이 제공되며, 연결 수락 후 연락처·주소 등이 추가 제공된다. 연결 전 비공개 사진 원본 열람과 사진 식별값 전달은 구별된다.
- 프로필 제공에 사업자등록증·사업자등록번호·로그인 이메일은 기본 포함되지 않는다. 회원이 채팅 등에 직접 재첨부하는 경우까지 ‘절대로 제공되지 않는다’고 표현하지 않았다.
- 자동 파기·완결된 탈퇴·법정대리인 확인·목적별 동의 증빙이 갖추어졌다고 확인되지 않았다.
- 등록 파일은 일반 사용자의 직접 덮어쓰기·삭제가 제한되는 구조다. 삭제 요청을 수행할 권한 있는 별도 서버 절차가 필요하다.
- 로그아웃은 현재 기기 세션 종료이며 서버 계정 삭제와 다르다. 기기 내 발송 실패 대기열도 별도로 관리해야 한다.
- 별도 광고·분석 SDK, GPS 추적, 직접 결제·정산, AI 신용심사 기능은 확인되지 않았다. 존재하지 않는 기능을 수집 목적으로 추가하지 않았다.

## 6. 게시·시행 전에 완료할 사항

### 운영정보와 사업 구조

- [ ] 사업자등록번호와 실제 등록사항, 주소 표시, 사업자 형태를 확인한다.
- [ ] 통신판매·통신판매중개·전기통신사업 해당 여부와 필요한 신고·정보공개 의무를 검토한다. ‘수수료를 받는다’는 사실만으로 특정 업종의 법적 요건을 모두 판단하지 않는다.
- [ ] 중개 상대방이 사업자인지 개인인지, 제공하는 실제 업무·책임이 무엇인지 확인한다. 개인 제공자가 포함되는 경우 전자상거래법 제20조의4 적용과 구분 표시를 검토한다.
- [ ] 개인정보 보호책임자와 담당 창구를 지정하고 전화·서면 요청을 실제 처리할 인력·권한을 마련한다. 소규모 사업자 관련 예외가 있더라도 법정 요건을 확인하며 대표자 책임이 없어지는 것으로 보지 않는다.
- [ ] 수수료 조건을 확정할 때 산식·부담자·세금·부과 시점·취소·부분수행·결제사·자동결제 여부를 채운다. 확정 전에는 청구하지 않는다.
- [ ] 공고·시행일, 공개 URL, 이전 버전 보관 위치를 확정한다.

### 가입과 동의

- [ ] 최초 소셜 로그인과 가입 중 자동 저장 전에 처리 내용을 안내한다. 동의 기반 처리를 나중의 가입완료 체크로 소급 정당화하지 않는다.
- [ ] 약관 동의, 개인정보 처리 안내, 선택정보 수집·이용 동의, 상대방별 제공 동의와 국외 이전 동의를 구별한다.
- [ ] 동의마다 문서·목적·항목·수신자·버전·일시·철회 결과를 증빙할 수 있게 한다. 현재의 `terms`·`privacy` 불리언만으로는 충분한 증빙이라고 보기 어렵다.
- [ ] 연령대 확인과 만 14세 미만 법정대리인 동의 확인, 미성년자 유료 계약 동의를 각각 설계한다. 생년월일 전체나 주민등록번호를 관행적으로 추가 수집하지 않는다.
- [ ] 사업자등록증의 실제 확인 목적·절차와 원본 보유 필요성을 정한다. 심사하지 않을 서류를 필수로 수집하는 방식은 축소하거나 변경한다.
- [ ] 프로필 선택항목에 대한 거부·철회 경로를 제공한다. 미입력만으로 불필요한 기본 기능을 막지 않는다.

### 거래처 제공

- [ ] 연결 전 코드 조회에서 이미 나가는 기본 프로필에도 적법한 제공 근거가 있는지 확인한다. 연결 수락 때 동의받아도 이전 제공이 소급 해결되지는 않는다.

6. 공고·시행일을 정하여 공개하고, 최초 수집·가입·거래·변경의 적절한 시점에 안내한다. 이전 문서와 동의 증빙을 관리한다.
