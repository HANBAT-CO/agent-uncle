# 가입 직후 역할별 시작 안내

최초 앱 소개와 별개로, 신규 회원이 가입을 완료하면 선택한 역할에 맞는 안내 세 장을 표시한다.

| 역할 | 1장 | 2장 | 3장 |
| --- | --- | --- | --- |
| 소매업자 | 상품·옵션·수량·배송지 공유로 실수 줄이기 | 미입금 및 입금 확인 현황 관리 | 다른 지역 사입삼촌과 연결하기 |
| 사입삼촌 | 받을 대금과 지급 상태 확인 | 여러 거래처의 요청 통합 관리 | 오늘 및 이번 달 사입 현황 확인 |

지급 안내는 **소매업자 수령·입금 확인 후 운영자가 지급하는 현재 흐름**을 따른다.
배송 후 30분 내 입금이나 자동 이체를 보장하지 않는다.

## 화면과 조작

- TDS 진행 표시, 텍스트 버튼, 하단 CTA와 기존 PageHeading·FigmaSurface·Item·FigmaIcon을 조합한다.
- 다음·이전 버튼으로 페이지를 넘기며, 마지막 장의 ‘사입삼춘 시작하기’ 또는 ‘건너뛰기’로 홈에 진입한다.
- 시스템 뒤로가기는 이전 장으로 이동한다. 첫 장에서는 가입 폼으로 돌아가지 않는다.
- 자동 넘김은 없다. 본문은 스크롤 가능하고 주요 버튼은 하단에 유지된다.
- 장 전환은 TDS StaggerIn 기본 효과를 사용한다. 동작 줄이기 설정에서는 즉시 표시한다.
- 저장 중에는 중복 조작을 막는다. 저장 실패 시 현재 안내와 재시도 메시지를 유지한다.

## 저장 범위

최종 가입 완료 저장 직전에 계정 ID별 안내 대기 상태를 기록한다. 아직 가입을 마치지 않았다면
안내 대신 가입 폼을 표시한다. 완료 또는 건너뛰기를 저장한 뒤에는 재로그인해도 반복하지 않는다.
기존 가입 완료 회원이나 프로필 수정에는 안내 대기 상태를 만들지 않는다.

로컬 모드는 로컬 settings, 서버 모드는 이 기기의 Sembast preferences에 저장한다.
기기 간 동기화 대상은 아니며, 다른 기기의 기존 가입 완료 회원에게 새 안내가 나타나지는 않는다.
가입 후 안내를 끝내지 않고 앱을 종료했다면 같은 기기에서 첫 장부터 다시 표시한다.
탈퇴 시 해당 계정의 안내 상태도 삭제한다. 서버 스키마 변경은 필요하지 않다.

## 확인

에뮬레이터를 사용하지 않고 TDS 정책 검사, Flutter 정적 분석 및 위젯·저장소 테스트로 확인한다.
역할별 페이지, 이전·완료·건너뛰기, 저장 실패 후 재시도, 재로그인, 계정별 상태,
작은 화면의 큰 글자와 동작 줄이기를 테스트한다.
