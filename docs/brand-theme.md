# 블랙·오프화이트와 그린 강조 테마

2026-10-11 제공된 로고와 그린 강조색을 적용했다. 화면 바탕·텍스트·일반 표면은
테마 변경 이전의 차콜·오프화이트·회색 팔레트로 복원했다. 기존 Figma 배치, Paperlogy,
TDS 컨트롤, 내비게이션과 업무 로직은 유지한다. 앱은 기존 AIT 설정에 따라 밝은 모드로
표시한다.

## 앱 아이콘과 스플래시

사용자가 제공한 `samchun-app-icon-sc-v4.svg`를 `samchun_app_icon.svg`로 보관하고
iOS·Android 런처 아이콘과 웹 아이콘에 적용한다. 모자에 ㅅㅊ 심볼이 들어간 흑백
캐릭터 원본을 유지하며 플랫폼별 마스크 여백만 조정한다.
[에셋 재생성 방법](../assets/README.md#앱-아이콘과-시작-화면)으로 모든 해상도를 함께 관리한다.

앱 시작 시 흰 배경 중앙에 같은 로고를 192 논리 픽셀로 표시한다. iOS LaunchScreen,
Android 시작 테마, 웹 엔진 로딩 화면에서 Flutter의 `AppSplashScreen`으로 이어지고,
서비스 초기화와 계정 확인이 끝나면 바로 다음 화면으로 넘어간다. 임의 대기 시간이나
자체 애니메이션은 추가하지 않는다. Flutter 화면은 TDS 에셋 컴포넌트로 구성한다.
초기화·계정 확인 실패 시에는 오류 안내와 재시도를 제공한다.

네이티브 아이콘과 시작 화면은 핫 리로드로 갱신되지 않으므로 앱을 다시 빌드·설치해야 한다.

## 로고와 팔레트

`assets/logos/saip_samchun_sc_symbol.svg`는 사용자가 제공한 원본 파일이다.
원본 검정 `#111111`, 경로, 415:254 비율을 유지하고 색상 필터 없이 `TdsAssetImage`로
표시한다. 온보딩·로그인은 폭 112, 홈 상단은 폭 40이며 계정명은 남은 영역에서 말줄임한다.
홈 상단 내비게이션과 콘텐츠 사이에는 16px 여백을 추가했다.

소셜 로그인은 [공식 제공사 버튼 원본](../assets/README.md#공식-소셜-로그인-버튼)의
로고·문구를 사용한다. 이미지 자체는 보존하고 표시할 때 로고·문구 전체를 클리핑해
Google 흰색/회색 1px 테두리, Kakao 노란색 컨테이너에 배치한다. 좌우 24 여백의
전체 폭, 높이 56, 모서리 12, 간격 12로 정돈하며 글자와 로고는 가로로 늘리지 않는다.
TDS의 터치·키보드·접근성 처리로 기존 로그인 경로를 실행한다.
두 로그인 화면이 같은 버튼 구성을 사용하며 연결 중에는 중복 실행을 막는다.

| 용도 | 값 |
| --- | --- |
| 주요 버튼·선택·포커스·내 채팅 | `#0C483E` |
| 제목·중요 수량 | `#101010` |
| 본문·보조 설명 | 기존 회색 단계 `#2D2D2D` / `#484848` / `#636363` |
| 화면 바탕·일반 카드 | 기존 오프화이트 `#EDECE3` / `#F5F4EE` |
| 선택 탭 | 그린 전경 + 시스템 Liquid Glass 선택 렌즈(iOS) |
| 비활성·장식·입력 안내 | 기존 회색 단계 `#A3A3A3` / `#808080` |
| 강조 안내 배경 | `#F2FFE8` |
| 주요 버튼 글자 | 흰색 |
| 보조 버튼 | 딥그린 12% 배경 + 딥그린 글자 |

기존 blue 계열 테마 토큰에 브랜드 초록을 대응시켜 TDS 컴포넌트가 같은 팔레트를
사용하게 한다. 그린은 버튼·선택·포커스·배지·내 채팅·강조 안내에 사용하고,
일반 바탕·본문·카드는 기존 중성색을 사용한다. 오류·위험 색상은 유지한다.
TDS의 nullable 보조 버튼 테마 훅으로
짙은 초록이 기본 명도 보정에 의해 회색으로 바뀌는 것을 방지한다. 기본 패키지 테마의
색 보정·비활성·로딩·키보드 동작은 유지한다.

## 검색창

사입·업무, 채팅, 거래처 목록은 공용 `AppSearchField`에서 기본 `TdsSearchField`를 사용한다.
검색창은 화면과 같은 `AppThemeData`를 상속한다. 바깥 배경과 하단 페이드는 화면의
오프화이트, 글꼴은 Paperlogy, 본문과 아이콘은 공통 회색, 커서와 선택 영역은 브랜드 그린을
사용한다. 입력면의 `opacity100`도 기존 `greyOpacity100`과 같은 차콜 5%에 연결해
푸른 회색이 섞이지 않게 한다. 검색창만 별도 흰색 테마로 분리하지 않는다.

별도 `Inset` 없이 좌우 여백은 TDS 기본 16을 사용해 목록 카드의 바깥선과 맞춘다.
검색창의 아이콘·높이·모서리·하단 페이드 구조는 패키지 기본값이다.

입력 즉시 목록을 필터링하며 검색어 앞뒤 공백은 무시한다. 결과가 없을 때는 검색 안내를
표시하고, 기본 삭제 버튼으로 전체 결과를 복원한다. 키보드 검색 버튼은 입력값을 유지한 채
키보드를 닫는다. 검색창에 임의 전환 애니메이션을 추가하지 않고 TDS 기본 동작을 사용한다.

## 표면

`FigmaSurface`의 기본 스타일은 불투명한 `solid`다. 홈의 확인할 일 카드,
사입 현황/오늘 업무 카드에 `glass`를 사용한다. 하단 탭과 알림 버튼은
[Apple Liquid Glass 어댑터](liquid-glass.md)를 사용한다. 거래 목록·입력 폼·상세 정보는
불투명 표면으로 유지한다.

- 반경 24, 기존 바깥 여백·안쪽 여백·터치 영역 유지.
- 흰색 55% → 기존 오프화이트 `#F5F4EE` 32% 표면, sigma 16 배경 블러.
- 흰색 95% 상단·측면 테두리, 차콜 15% 하단 경계.
- 차콜 8%, 아래 8, blur 24의 그림자와 정적인 흰색 빛 반사.
- 홈 바탕은 단색 `#EDECE3`. 홈 전체와 카드의 라임 그라데이션을 제거하고,
  글자·아이콘은 불투명하게 표시한다. 선택 탭은 시스템 렌즈와 그린 전경으로 구분한다.
- 카드 내부로 블러를 클리핑하고 겹치지 않는 홈 카드만 `BackdropGroup`을 공유.
  네이티브 탭·알림 버튼을 별도의 Flutter 블러로 감싸지 않는다.
- 고대비 모드에서는 블러·투명도·그림자를 제거하고 불투명 표면과 차콜 테두리를 사용.

## 검증

원본 SVG는 유지한다. 바탕·일반 카드·유리 표면의 합성 색상을 기준으로
본문(`grey600`) 대비는 최소 5.07:1, 제목은 16.05:1, 주요 버튼은 10.44:1,
보조 버튼은 최소 7.21:1이다. 색상 계산 결과와 이번 캡처는
`.context/neutral-theme/`에 보관한다.

화면 테스트는 320/390/430 너비와 실제 TDS 100/180% 글자 크기에서 홈 로고·긴 계정명,
온보딩·로그인과 탭 이동을 확인한다. 별도 테스트에서 유리 표면의 버튼이 눌리는지,
고대비 전환으로 레이아웃이 바뀌지 않는지 확인한다. 기존 앱 업무 테스트와 TDS
버튼·입력·체크박스·스피너·하단 CTA·채팅 말풍선 테스트도 실행한다.

기기 통합 테스트는 온보딩·소셜 로그인 화면과 양쪽 역할의 홈, 홈 스크롤, 요청 상세,
네이티브 입력, 확보·전달·수령, 채팅을 캡처한다. 테스트는 격리된 메모리 데이터를
사용하며 실제 OAuth 로그인이나 서버 데이터는 변경하지 않는다.

이전 그린 테마 검증: 정적 분석 이슈 없음, 기존 앱 테스트 36개 통과(웹 전용 7개 제외),
브랜드 표면·글자 크기 테스트 7개 통과, 관련 TDS 테스트 40개 통과. 탭 내부 정렬을
보정한 뒤 화면 회귀 테스트 13개를 다시 통과했고, iOS 26.5 / Android API 36.1의
온보딩·로그인·업무 통합 테스트도 통과했다. 최종 캡처는
`.context/brand-refresh/after/`, 기존 홈과의 비교는 `.context/brand-refresh/comparison.png`다.

블랙·오프화이트 복원 후 검증: 정적 분석 이슈 없음, 앱 테스트 43개 통과(웹 전용 7개 제외).
320/390/430 너비, TDS 100/180% 글자 크기, 고대비 모드와 유리 표면 터치 검증을 포함한다.
iOS 26.5 시뮬레이터의 온보딩·로그인·양쪽 역할 홈·입력·업무·채팅 통합 테스트도 통과했다.
이전 그린 테마와 비교한 캡처는 `.context/neutral-theme/comparison.png`다.
